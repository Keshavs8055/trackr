  - Fully wired `OMDbAdapter`, `OpenLibraryAdapter`, and `GithubAdapter` into `MetadataService` (`src/services/providers/metadata-service.ts`).

* Mock Data Tag Normalization:
  - Updated `DEFAULT_MOCK_RESOURCES` in `resource-service.ts` to use canonical normalized tags (`#movie`, `#book`) matching the tag normalization engine rules.

3. ARCHITECTURAL IMPROVEMENTS
--------------------------------------------------------------------------------
* Provider Key Isolation & Security Vault:
  - Enforced single-source ownership of decrypted secrets inside `CredentialService`.
  - Providers no longer store raw API key fields in private instance properties.
  - Enabled IndexedDB (`secureStorage`) vault persistence with SHA-256 integrity verification upon decryption.
  - Inactivity sweep automatically purges in-memory credentials every 60 seconds (15-min threshold) and on window unload.

* Clean Component Layout Abstraction:
  - Centralized connection diagnostics (`ConnectionStatus`) into the layout module for clean reuse across desktop sidebar and mobile headers.
