# TRACKR V2 FOUNDATION - PROJECT INTEL

## 1. Project Overview
Trackr (Archive V2) is a minimalist, offline-first personal resource management platform. It generalizes item tracking into a universal **Resource** platform supporting movies, books, TV shows, articles, websites, courses, GitHub repos, tools, podcasts, games, notes, and custom resources with optional metadata enrichment.

## 2. Layered Architecture & Data Flow
The system follows a strict layered architecture:
```
[UI Components & Search Modal]
       │
       ▼
[Custom Hooks (useResources, useProviderSearch, useIntegrations)]
       │
       ├─────────────────────────────────┐
       ▼                                 ▼
[Resource Service]              [Provider Service & Managers]
  (Firestore CRUD)                 │ (Search, Metadata & Credentials)
       │                           ├───────────────┬────────────────┐
       ▼                           ▼               ▼                ▼
[Firestore 'resources']     [ProviderCache] [BaseProvider] [CredentialService]
 (Offline Persistence)     (Shared Cache)  (OMDb, OpenLib) (Encrypted Keys)
```

- **Offline-First & Source of Truth**: The Trackr database is the absolute source of truth. All manual creations work completely offline. Provider metadata is stored once permanently in the resource's `metadata` dictionary.
- **Provider Search Architecture**: Single-provider search auto-routed by resource type (e.g. `movie` -> OMDb, `book` -> Open Library) with debounced input, session cache (`src/cache/provider-cache.ts`), and non-blocking manual creation fallback.
- **Strict Field Ownership**: Metadata refresh strictly preserves user-managed fields (`title`, `tags`, `notes`) while updating provider-managed fields (`metadata`, `image`, `providerUpdatedAt`, `metadataVersion`).
- **Inline Metadata Search**: Searches are routed automatically and debounced inline during Quick Add when resource tags like `#movies` (OMDb) or `#books` (Open Library) are entered, removing the need for a separate search dialog.
- **Secure Credentials Hydration**: Saved API credentials are encrypted/decrypted in local storage and automatically loaded on application startup or mock login to ensure online connectivity.
- **Standardized Provider Errors**: Unified `AppError` class with specific error categories (`INVALID_API_KEY`, `RATE_LIMITED`, `NO_RESULTS`, `NETWORK_ERROR`, `UNCONFIGURED_PROVIDER`, `PROVIDER_UNAVAILABLE`).
- **Optimistic UI Updates**: React Query mutations perform instantaneous `onMutate` cache updates with `onError` rollback context.

## 5. Resource Data Schema (`src/types/index.ts`)
- **Resource**:
  - `id`: string
  - `userId`: string
  - `title`: string
  - `type`: ResourceType (`movie` | `book` | `tv` | `article` | `website` | `course` | `github` | `tool` | `podcast` | `game` | `note` | `custom`)
  - `provider`: ProviderName (`manual` | `omdb` | `openlibrary` | `tmdb` | `google_books` | custom)
  - `providerId`?: string
  - `status`?: string
  - `notes`?: string
  - `tags`: string[]
  - `metadata`: Record<string, unknown> (Strict JSON metadata)
  - `metadataVersion`?: number
  - `metadataSource`?: { provider: string; version: string; schemaVersion: number }
  - `image`?: string
  - `rawInput`?: string
  - `createdAt`: number
  - `updatedAt`: number
  - `lastSynced`?: number
  - `providerUpdatedAt`?: number

## 6. Reserved Tag Type Inference
Quick Add parses inline hashtags. `type` is inferred **strictly** from `RESERVED_TYPE_TAGS`:
- `#movie`, `#movies` -> `movie`
- `#book`, `#books` -> `book`
- `#tv`, `#show`, `#shows` -> `tv`
- `#game`, `#games` -> `game`
- `#podcast`, `#podcasts` -> `podcast`
- `#article`, `#articles` -> `article`
- `#website`, `#websites` -> `website`
- `#course`, `#courses` -> `course`
- `#github`, `#repo` -> `github`
- `#tool`, `#tools` -> `tool`
- `#note`, `#notes` -> `note`
Unrecognized tags default to `type = "note"`.

## 7. Migration & Security Architecture
- **Lazy Migration**: On first query, if `resources` is empty, `resource-service.ts` converts legacy `items` subcollection to `resources` and sets a local migration flag to avoid repeated queries.
- **Web Crypto AES-GCM 256-bit Key Encryption**: Provider API keys are encrypted using Web Crypto API (`window.crypto.subtle` AES-GCM 256-bit) with PBKDF2 key derivation (100,000 iterations + SHA-256). Legacy Base64 credentials are auto-migrated on startup.
- **Custom Confirmation UI**: All native browser `confirm(...)` and `alert(...)` popups are replaced with `ConfirmDialog` and custom inline notification banners.
- **Code Cleanup**: Removed legacy alias files (`use-items.ts`, `item-card.tsx`, `item-details.tsx`), migrating all imports to `@/hooks/use-resources`.
- **Firestore Security Rules (`firestore.rules`)**: Uses recursive subcollection matching (`match /{document=**}`) under `/users/{userId}` to allow full access to `/resources`, `/items`, `/collections`, `/audit_logs`, and future subcollections (`/notes`, `/activities`).
